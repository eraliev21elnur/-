# Управление контентом FULL CORE

## Демонстрационный режим

По вашему запросу включён `demoMode: true` в `src/data/site.ts`. Пять примеров в `src/data/demo.ts` показывают заполненный сайт с фотографиями, галереями и рабочими локальными видео. Все отмечены Sample / Preview; это не ваши проекты. Источники и лицензии — `public/media/demo/CREDITS.md`.

Чтобы перейти к реальному портфолио: заполните черновики в `src/data/projects.ts`, поставьте им `status: "published"`, затем переключите `demoMode: false`. Это одновременно уберёт демо-кейсы, баннер и sample hero. Ваш собственный `site.showreel`, если задан, будет показан вместо демо. После переключения можно удалить `public/media/demo/` и пересобрать сайт. Не отправляйте демо-версию как подтверждение авторства работ.

## Личная информация

Редактируйте `src/data/site.ts`: бренд, tagline, subtitle, location, about, approach, tools, disciplines, ссылки, email, available и availability. Пустые email, portrait и cv не создают неработающих кнопок. `url` — реальный HTTPS-домен, без пути. После его добавления пересоберите сайт.

`public/core-study.svg` — абстрактная графика интерфейса, не пример вашей работы. Для showreel задайте `showreel` как объект Media (см. ниже). Он заменит графику и будет запускаться только по клику. Для фотографии: `portrait: '/media/portrait.webp'`. Для CV: `cv: '/media/full-core-cv.pdf'`.

## Быстрое добавление проекта

1. Загрузите принадлежащее вам видео на YouTube/Vimeo. Разрешите встраивание; YouTube может быть Unlisted, но не Private.
2. Подготовьте обложку WebP/AVIF (обычно до 1600 px по длинной стороне, желательно 100–250 KB).
3. Положите её в `public/media/my-project.webp`.
4. В `src/data/projects.ts` заполните существующий черновик или добавьте объект в `projects`:

```ts
{
  id: 'your-unique-id',
  slug: 'your-project-slug',
  title: 'Your confirmed project title',
  category: 'motion',
  status: 'published',
  // year: 2026, // Только подтверждённый год
  description: 'A short, factual description of the work.',
  role: ['Motion design', 'Editing'], // Только реальные роли
  tools: ['After Effects'],
  coverImage: '/media/my-project.webp',
  coverAlt: 'Describe the actual image',
  coverAspectRatio: '16/9',
  featured: true,
  featuredOrder: 1,
  media: [{
    id: 'main-film',
    type: 'youtube',
    url: 'REPLACE_WITH_REAL_YOUTUBE_ID',
    thumbnail: '/media/my-project.webp',
    aspectRatio: '16/9',
    caption: 'Optional factual caption',
  }],
}
```

Это образец структуры: замените URL и текст, прежде чем публиковать. Сборка отклоняет опубликованные проекты без медиа или с некорректными ссылками провайдера.

5. `npm run build` → загрузите содержимое `dist/` или отправьте изменения в подключённый GitHub.

## Форматы медиа

- YouTube: `type: 'youtube'`, URL watch/shorts/youtu.be или 11-символьный ID.
- Vimeo: `type: 'vimeo'`, URL или числовой ID. Unlisted URL с privacy hash поддерживается. Проверьте разрешения домена в Vimeo.
- Видео-файл: `type: 'localVideo'`, `url: '/media/film.mp4'`, желательно MP4 H.264/AAC, отдельная обложка. Скачивание начинается после Play. Большие ролики лучше размещать на YouTube/Vimeo.
- Фото: `type: 'image'`, `url: '/media/image.webp'`, `alt: 'Accurate image description'`. Укажите aspectRatio, чтобы зарезервировать место. Изображения загружаются лениво, увеличение — по клику, закрытие — кнопкой или Escape.

Все объекты имеют уникальный `id` внутри media. Соотношения: `'16/9'`, `'9/16'`, `'1/1'`, `'4/3'`. Вертикальные видео ограничены по ширине, не обрезаются. Добавьте 2–3 Media в один chair campaign, а не три отдельных проекта. Первый объект — главный материал. Остальные выводятся ниже; опциональные role, tools, process, credits и externalLinks отображаются только при наличии. `client`, `tags`, `subtitle`, `year` также необязательны.

Для локальных файлов используется путь **без public**: `/media/file.webp`. Не кладите секретные материалы в public: даже черновик не делает лежащий там файл приватным.

## Порядок, фильтры и скрытие

- Название: `title`. Slug — постоянный URL; изменение требует редиректа со старого адреса.
- Главная: `featured: true`, порядок — `featuredOrder` по возрастанию.
- Каталог: порядок объектов в массиве. Первоначально 12 карточек, затем Load more.
- Скрыть: `status: 'draft'`. Это убирает страницу из следующей сборки и sitemap. Удалите старую директорию проекта с ручного хостинга, если она осталась от прежней версии.
- Новая категория: добавьте `{ id: 'your-id', label: 'Your label' }` в `categories`, используйте ID в проектах. Не добавляйте AI-категорию до появления реальных работ.
- Пустая категория показывает честное пустое состояние. Шесть исходных записей — рабочие группы для подготовки, не готовые кейсы.

## Перед отправкой рекрутеру

Проверьте фактическое авторство, название, роли, разрешение на публикацию и рабочие ссылки. Добавьте лучшие Motion / Studio / Film кейсы, обложки и контакт. Проверьте плееры на телефоне и на реальном домене: ограничения площадок, регионов или браузера нельзя проверить только сборкой. При необходимости включите субтитры в YouTube/Vimeo, для локального видео подготовьте доступную версию с субтитрами. Не приписывайте AI, показатели, награды или участие в чужих работах.
