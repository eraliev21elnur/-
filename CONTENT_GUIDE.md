## Добавить проект

1. Подготовьте видео на YouTube/Vimeo/Instagram либо оптимизированный MP4 и обложку.
2. Положите локальные файлы в public/media/portfolio/ или другую папку внутри public/media/.
3. Добавьте объект в projects. Локальные URL пишутся без public, например `/media/portfolio/film.mp4`.
4. Задайте `status: "published"`. `draft` скрывает проект из всех публичных списков и маршрутов.
5. Выполните проверки и `npm run build`, затем опубликуйте изменения.

Минимальная структура (шаблон, не готовая работа):

```ts
{
  id: 'your-project',
  slug: 'your-project',
  title: 'Actual project title',
  category: 'motion',
  status: 'published',
  coverImage: '/media/portfolio/your-cover.webp',
  coverAspectRatio: '16/9',
  media: [{
    id: 'main',
    type: 'youtube',
    url: 'YOUR_VIDEO_ID',
    thumbnail: '/media/portfolio/your-cover.webp',
    aspectRatio: '16/9',
  }],
}
```

Описание, subtitle, year, client, role, tools, process, credits и externalLinks необязательны. Не добавляйте неподтверждённые программы, роли, клиентов и даты. ID и slug должны быть уникальны; slug — латиница, цифры и дефисы.

## Порядок и избранное

Порядок объектов задаёт порядок каталогов. `featured: true` добавляет кейс в избранное; `featuredOrder` задаёт приоритет. На главной максимум четыре кейса. Текущий порядок: Introduction → Crypto Heist → Vash Product → личный YouTube-фильм. Introduction — первый в Video; Crypto Heist — первый в Motion/3D, LOVV66 следует за ним. Четыре студийных фильма кресел YEPO объединены в один кейс, каждый доступен внутри него.

## Категории и 3D-фильтры

Категории: motion, commercial, film, 3d-vfx, design. Video объединяет commercial/film; поле videoType задаёт studio-commercials, product-reviews, reels-ads или personal-films.

На 3D/VFX есть All / 3D Videos / 3D Illustrations. На объединённой странице дополнительно выделен Motion. Проект считается иллюстрацией, если все его media имеют type image. Для галереи иллюстраций не добавляйте туда технические видео: при необходимости создайте отдельный кейс.

Новая категория добавляется в projects.ts и реестр disciplines.ts. Новые проекты существующих категорий компонентов не требуют. Кнопка Load More ограничивает первоначальный список: видео/iframe не создаются пачкой.

## Медиа и обложки

- YouTube: URL или 11-символьный ID. Оригинальная обложка: `https://i.ytimg.com/vi/ID/maxresdefault.jpg`; `thumbnailFallback` и `coverFallback` могут указывать на `https://i.ytimg.com/vi/ID/hqdefault.jpg`. Это исходные обложки YouTube, а не заменяющие рисунки. В текущей среде скачивание с этого домена ограничено, поэтому обложки запрашиваются браузером у YouTube. Отдельный iframe загружается только по Play и использует youtube-nocookie.
- Vimeo: URL или ID; разрешите встраивание в настройках видео. Unlisted URL с privacy hash поддерживается.
- Instagram: `type: 'instagram'`, ссылка `/p/CODE/` или `/reel/CODE/`. Настоящие обложки текущих девяти публикаций сохранены локально. По Play загружается официальный embed, а Open on Instagram остаётся доступным как запасная ссылка. Платформа может ограничивать встраивание или требовать вход.
- MP4: `type: 'localVideo'`, H.264/AAC, progressive faststart. До Play src не устанавливается. После ухода со страницы плеер останавливается и выгружает источник. Веб-экспорты архива сохраняют пропорции и ограничены 1080p/1080×1920; исходники хранятся отдельно.
- Фото: `type: 'image'`, URL, содержательный alt. Поддерживаются 16/9, 9/16, 1/1, 4/5 и другие положительные отношения W/H. Галереи и просмотрщик не обрезают изображение. Закрытие — кнопкой или Escape.

`coverImage` — обложка карточки; `thumbnail` — обложка плеера. Для внешних YouTube-обложек задавайте запасной вариант через coverFallback/thumbnailFallback. Первый media — главный, остальные выводятся внутри кейса. Несколько материалов одной кампании лучше хранить вместе.

YEPO Product Visuals содержит изображения из 13 подтверждённых владельцем карточек Kaspi и ссылки на оригиналы. Не считайте остальные материалы YEPO автоматически авторскими. Yandex Station Max — неофициальное тестовое задание, Vash Product и The Down используют вымышленные продукты. Озвучка и актёр в студийной кампании предоставлены другими участниками. Сохраняйте эти уточнения при правке ролей.

## Переводы

Общий интерфейс: src/i18n/messages.ts. Для проекта:

```ts
translations: {
  ru: { title: 'Название', description: 'Описание', role: ['Видеомонтаж'] },
  kk: { title: 'Атауы', description: 'Сипаттамасы', role: ['Бейнемонтаж'] },
}
```

Для media поддерживаются caption/alt в translations.ru/kk. Названия брендов, исполнителей, инструментов, ID и ссылки не переводятся. Файлы сохраняйте в UTF-8 без BOM, с переводами строк LF. Казахский код — kk, отображаемая кнопка — KZ. На телефоне переключатель языка виден рядом с закрытым меню.

## Музыка

Добавляйте свои записи в src/data/tracks.ts: id, title, artist, status, src, artwork, duration (секунды), year при наличии. Порядок объектов — порядок плейлиста. Файлы размещаются в public/media/music/tracks/ или по прямому HTTPS-адресу аудио. Страница Spotify/SoundCloud не является MP3: добавляйте её в externalLinks.

Обложка показывается в списке и нижней панели. Предпочтительны квадратные WebP/JPEG 512–1024 px. Сама MP3-запись не загружается до Play. Используется один плеер, поэтому треки не накладываются; следующая песня автоматически не запускается. При уходе с Music воспроизведение останавливается. Высота закреплённой панели учитывается в отступах и safe area телефона.

## Проверка и публикация

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

Проверьте маршрут кейса, Play, обложку, роли и мобильный экран. Файл, лежащий в public, всегда публичен, даже если его запись draft. Не помещайте туда оригинальный ZIP, закрытые материалы или гигабайтные исходники. В обычный GitHub нельзя добавлять файл больше 100 MiB. Для длинных видео удобнее YouTube/Vimeo.

Для GitHub Pages workflow использует SITE_BASE=/- и VITE_SITE_URL. Корневые деплои поддерживаются теми же данными. Подробные инструкции для GitHub Pages, Cloudflare и Beget — DEPLOYMENT.md.
